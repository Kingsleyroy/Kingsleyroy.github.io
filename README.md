# Kingsley Roy — portfolio

3D animated portfolio built with plain HTML/CSS/JS.

- `index.html` — page content (edit text here)
- `css/style.css` — design tokens at the top (`:root`)
- `js/main.js` — three.js scene, scroll choreography, page transitions
- `js/vendor/` — three.js, GSAP + ScrollTrigger, Lenis (self-hosted, no CDN needed)
- `images/portrait.webp` — cut-out portrait used in the 3D hero

Serve locally with `python3 -m http.server` and open http://localhost:8000.
